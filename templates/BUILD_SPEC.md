# Build-spec template

Copy this template and replace the prompts with your own project details. This is a blank teaching template, not a Pryvo feature specification.

## Problem

Who needs this? What is difficult today? Describe a concrete situation.

## Intended outcome

What should a person be able to do after this task is finished?

## Current behavior

What already exists? What evidence supports that description?

## Required behavior

Describe the observable changes, including what happens when the action cannot finish.

## Constraints

What limits must the builder preserve? Which choices are already fixed?

## Outside this task

What should the builder leave for a separate task?

## Open choices

Which questions need an answer before implementation continues?

## Acceptance criteria

Write specific outcomes that can be checked. Identify the setting in which each will be verified.

## Requested report

Ask for what changed, what was checked, what failed or was skipped, what remains uncertain and the proposed next step.
